# BT-KEY

BT-KEY 固件发布与 iOS App 支持页面。 / Firmware releases and support for the BT-KEY iOS app.

## 这是什么 / What is it

BT-KEY 是一个自制的摩托车蓝牙数字钥匙模块：把车辆的备用智能钥匙装进模块，由手机通过蓝牙控制。
配合 iOS App，靠近自动开锁、离开自动上锁，也可以在 App、Siri、快捷指令里手动开关锁。

BT-KEY is a DIY Bluetooth digital key module for motorcycles with a smart key. The iOS app locks and
unlocks the bike automatically as you approach or walk away, or manually from the app, Siri and Shortcuts.

## 常见问题 / FAQ

- **需要硬件吗？ / Do I need hardware?** 需要 BT-KEY 模块。没有硬件可以在 App 首页进入「演示模式」体验。
  Yes. Without a module, tap "Try demo mode" on the home screen.
- **首次连接 / First connection**：先在 iPhone「设置 → 蓝牙」用模块的配对码配对，再打开 App。
  Pair the module in iOS Settings → Bluetooth with its passkey, then open the app.
- **固件升级 / Firmware update**：App「设置 → 固件升级 → 检查更新」，车辆需熄火。
  Settings → Firmware upgrade → Check for updates, with the ignition off.
- **自动开锁太远或太近 / Auto unlock too far or too close**：在「设置 → 自动开关锁距离」调整阈值，可在「诊断」页观察信号。
  Adjust thresholds in Settings; watch the live signal in the Diagnostics tab.
