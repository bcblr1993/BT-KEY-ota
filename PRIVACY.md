# BT-KEY Privacy Policy / 隐私政策

Last updated / 更新日期：2026-09-29

## English

BT-KEY is an iOS app that connects over Bluetooth Low Energy to a BT-KEY module the user
installs on their own motorcycle, to lock and unlock it and to adjust the module's settings.

**We do not collect, store on any server, share, or sell any personal data.**

- **Bluetooth.** The app uses Bluetooth only to communicate with the user's own BT-KEY module
  (status, lock/unlock commands, settings, signal strength and firmware updates). This data stays
  between the phone and the module.
- **Test logs.** If the user starts a test recording, signal strength and connection events are
  saved only on the device. They leave the device only if the user chooses to share an exported file.
- **Firmware updates.** When checking for updates, the app downloads a public release manifest and
  firmware file over HTTPS from GitHub (`github.com/bcblr1993/BT-KEY-ota`). No account, identifier or
  personal information is sent by the app. GitHub may log standard request data such as IP address
  under its own privacy statement.
- **No analytics, advertising, tracking or third-party SDKs.**
- **Siri & Shortcuts.** The unlock/lock actions run on the device; no data is sent to us.

Children: the app is not directed at children under 13.

Contact: open an issue at https://github.com/bcblr1993/BT-KEY-ota/issues

## 简体中文

BT-KEY 是一款 iOS App，通过低功耗蓝牙连接用户自行安装在自己摩托车上的 BT-KEY 模块，用于开锁、上锁和调整模块设置。

**我们不收集任何个人数据，不上传到任何服务器，也不共享或出售。**

- **蓝牙**：仅用于与用户自己的 BT-KEY 模块通信（状态、开关锁指令、设置、信号强度、固件升级），数据只在手机和模块之间传输。
- **测试记录**：用户主动开始记录时，信号强度和连接事件只保存在本机；只有用户自己选择分享导出文件时才会离开手机。
- **固件更新**：检查更新时，App 通过 HTTPS 从 GitHub（`github.com/bcblr1993/BT-KEY-ota`）下载公开的版本清单和固件文件，App 不发送任何账号、标识或个人信息。GitHub 可能按其自身隐私声明记录 IP 地址等常规请求信息。
- **没有**统计分析、广告、追踪或第三方 SDK。
- **Siri 与快捷指令**：开锁、上锁动作在本机执行，不向我们发送任何数据。

联系方式：在 https://github.com/bcblr1993/BT-KEY-ota/issues 提交 Issue。
